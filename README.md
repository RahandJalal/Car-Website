# 🚗 Car Showcase & Dealership Website

A modern, responsive front-end website designed for browsing cars, viewing specifications, and exploring dealership offerings. Built with clean semantic HTML5, modern CSS3 layouts, and dynamic JavaScript interactions.

---

## ✨ Features

- **Responsive Design:** Fully optimized layout for desktops, tablets, and mobile screens.
- **Interactive UI:** Smooth navigation, car preview galleries, and interactive buttons powered by JavaScript.
- **Clean Structure:** Well-organized file tree separating markup, styling, and logic.

---

## 🛠️ Built With

- **HTML5:** Semantic structure and content organization.
- **CSS3:** Modern layouts using Flexbox/Grid, custom transitions, and media queries.
- **JavaScript (Vanilla ES6):** Dynamic UI interactions and DOM manipulation.
